# D2D Audit Services

D2D Audit Services is a compliance automation platform for companies undergoing audit, in the same category as Vanta and Drata. The first release covers IT frameworks, starting with ISO 27001 and SOC 2, with manufacturing and IoT/OT frameworks planned later on the same core. The product is in design, and there is no application code yet. Locked decisions are in [DECISIONS.md](DECISIONS.md).
